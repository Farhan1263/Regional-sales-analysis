📊 Regional Sales Analysis
📌 Overview

This project focuses on analyzing regional sales data across the U.S. to uncover trends, evaluate profitability, and identify growth opportunities. Using Exploratory Data Analysis (EDA) and an interactive dashboard, the project provides actionable business insights for data-driven decision-making.

🎯 Problem Statement

Businesses often face inconsistent revenue and profit performance across regions, with limited visibility into:

Seasonal trends
Top-performing products (SKUs)
Channel-wise profitability

Goal:
Leverage historical sales data to identify key growth drivers and optimize business strategy.

🛠️ Approach
🔹 Phase 1: Exploratory Data Analysis (EDA)
Data cleaning and preprocessing
Feature engineering (profit, margin, time features)
Trend, correlation, and distribution analysis
🔹 Phase 2: Dashboard Development
Built interactive dashboard (Power BI)
Enabled filtering by region, product, channel, and time
Visualized KPIs and performance metrics
📂 Dataset Features
Identifiers: Order ID, Customer Name
Financials: Revenue, Cost, Profit, Profit Margin %
Products: Product Name, Quantity, Unit Price
Geography: State, Region
Time: Month, Year
Planning: Budget data
🔍 Key Insights
📈 Seasonality: Peak sales in May–June, lowest in January
🛍️ Top Products: Products 25 & 26 drive ~25% of revenue
📦 Channel Performance:
Wholesale: 54% of total sales
Export: Highest profit margins (~38%)
🌍 Regional Trends:
West region leads in sales
Northeast underperforms
👥 Customer Concentration:
Few top customers contribute major revenue
💡 Recommendations
🎯 Run seasonal campaigns to stabilize revenue dips
📊 Focus on high-performing SKUs and optimize low performers
🌐 Expand export channels for higher margins
📍 Invest in underperforming regions (Northeast, Midwest)
💰 Monitor and improve low-margin orders
📊 Dashboard Preview

The Power BI dashboard includes:

Performance summary

Revenue scenario analysis
